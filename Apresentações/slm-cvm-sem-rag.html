04 · engenharia de coleta

O que quase parou o pipeline

  • Catálogo oculto: portal exibia só 10 itens → parâmetros de consulta + paginação simulados (>500 itens por categoria).
  • Dois layouts: anexos em tabela (normas antigas) vs links soltos (novas) — coleta adaptada aos dois.
  • PDFs: texto integral preso em anexos; cabeçalhos/rodapés institucionais filtrados na extração.
  • gov.br 404: links antigos quebrados → recuperados por cruzamento com o acervo local.
  • Windows: paths >260 chars travaram o Git → suporte a caminhos longos habilitado.
  • Git leve: 326 MB de binários (PDF/DOC) fora do versionamento; colisão multi-tag resolvida por subpasta.

10 · iteração 2 — prompt engineering

Matou a invenção. Bateu no teto da atenção.

O que funcionou

Âncoras [NNN] + data DD/MM/AA + campo altera/revoga extraído da ementa · proibição explícita no topo e rodapé · temp 0, top_k 1, top_p 0.1 → zero relações inventadas nas normas localizadas.

O que sobrou — Lost in the Middle

250 linhas / 32.899 chars no SYSTEM → erro de ponteiro: citou [027] no lugar de [086], [222] no lugar de [161]; misturou conteúdo de linhas distantes. Limite físico de atenção do 7B.

Conclusão do relatório: antes de qualquer vetor, enviar menos linhas — pré-filtro leve em Python sobre o índice, 1 a 5 normas por pergunta.

11 · src/consultar_cvm.py — a virada

Pré-filtro: 3 rotas, zero vetor

① Número explícito

Regex captura "nº 86", "Resolução 175", "CVM 24" → match exato no índice. Sem chance de ponteiro errado.

② Palavras-chave

Normaliza acentos, remove stopwords, pontua norma+tag+assunto → top-5 por score de tokens.

③ Panorâmica

"mais recentes / principais / 2026" → as 8 normas de maior número (251, 250, 249…).

  • Match único → contexto ganha os 900 primeiros chars do texto oficial da norma.
  • num_ctx caiu de 16384 → 4096; contexto vazio → bloqueio imediato, sem gastar GPU.
12 · o coração — buscar_normas()

Dez linhas que venceram o 7B

nums = re.findall(r"(?:resolu[çc][ãa]o(?:\s+cvm)?\s*(?:n[º°o.]*\s*)?|cvm\s*|n[º°]\s*)(\d{1,3})\b",
                  pergunta, flags=re.IGNORECASE)
if nums:                                   # rota ①: número explícito → exato
    return [i for i in indice if num(i["norma"]) in alvos][:top_k]

tokens = [t for t in re.findall(r"[a-z0-9]+", sem_acento(pergunta))
          if len(t) >= 3 and t not in STOPWORDS]
score = lambda i: sum(1 for tok in tokens
                      if tok in sem_acento(i["norma"] + i["tag"] + i["assunto"]))
return sorted((i for i in indice if score(i) > 0),
              key=score, reverse=True)[:top_k]   # rota ②: top-5

Python padrão (re, json, unicodedata, urllib) — zero dependência externa. O "RAG" aqui é um for com contador.
